# Elyria Build Tool — Buyer One-Pager

**Scope it. Layer it. Prove it before it moves.**

Use Elyria Build Tool when a system action can create real consequence: payment, access, approval, recommendation, AI-agent movement, workflow transition, or policy-bound decision.

A build-ready governance blueprint defining what is governed, what consequence is protected, what authority is required, what evidence must exist, when movement is admitted/held/refused, and what must be receipted and replayable.

## Why it matters

Most systems log consequence after execution. Elyria scopes the proof corridor before execution binds.
