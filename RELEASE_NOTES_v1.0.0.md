# Elyria Build Tool v1.0.0

## Release title

Elyria Build Tool v1.0.0 — Governance Intake and Blueprint Generator

## Product line

Scope it. Layer it. Prove it before it moves.

## Summary

Elyria Build Tool is a buyer-facing governance intake and blueprint generator for consequence-bearing automation.

It helps teams define what must be governed before implementation begins, including the governed object, consequence surface, authority requirements, evidence requirements, admit / hold / refuse logic, receipt requirements, replay requirements, pilot corridor planning, protected scope, and commercial access boundary.

## Included surfaces

- Governance build blueprint
- Governed object definition
- Consequence mapping
- Authority requirements
- Evidence requirements
- Admit / hold / refuse matrix
- Failure-mode surface
- Receipt requirements
- Replay requirements
- Pilot corridor plan
- Protected scope
- Commercial access boundary
- Validation report

## Boundary

This release is a public-safe governance intake and blueprint tool.

It does not disclose protected Elyria Systems runtime machinery, validator internals, production proof-corridor implementation, or controlled buyer-specific enforcement logic.

Show the geometry. Protect the machinery.
